# Changelog

## 1.0.0 (build 1) — initial public baseline

- Local application usage history and dashboard.
- History export and manual deletion.
- Daily and weekly usage reports.
- Public MIT-licensed source and verified release automation.
- Universal Mac download with ad-hoc signing, explicit notarization warning, checksums,
  and GitHub build provenance.

This records the current version as the first public release baseline; it does not
claim earlier build numbers were separately published releases.
